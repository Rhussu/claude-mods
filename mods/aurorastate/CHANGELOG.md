# Changelog

All notable changes to `aurorastate`. Versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-31

First public release.

- A framed line above the prompt showing Claude's state (working / your turn), context use and its trend, plan limits, the model, an effort meter and the git branch.
- Bars and text in the Aurora palette, adapting to the terminal width.
- English and Spanish, chosen automatically or with the `language` option.
- A one-time notice on first run explaining what the mod reads and how to hide it.
